# Tema (neytral grafit) — skrinshotlar

Bu papkada avval «oldin / keyin» skrinshotlari turardi (36+ PNG, ~6.5 MB). Repoga og'irlik bo'lmasligi uchun olib tashlandi; ular faqat lokal ishlab chiqarish uchun.

Qayta yaratish (360 px, qorong'i va och, KalkiFit + Ro'zg'or ekranlari):

```bash
node tools/dizayn/tema-shot.mjs oldin    # yoki: keyin  →  docs/tema/<teg>-<ekran>-<dark|light>.png
```

`*.png` `.gitignore` da — tasodifan commit bo'lmaydi. Papka (`docs/`) saytdan tarqatilmaydi: `functions/_middleware.js` `/docs/*` ga 404 qaytaradi (verify-all 36-band tekshiradi).
